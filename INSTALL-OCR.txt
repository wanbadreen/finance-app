Finance App — Receipt Scan / OCR

Before starting Vite, run this once inside your finance-app folder:

npm install tesseract.js@7.0.0

Then run your app normally:

npm run dev

For phone testing on the same Wi-Fi:

npm run dev -- --host 0.0.0.0

Receipt Scan supports JPG, PNG and WebP images.
PDF receipts can still be uploaded, but this OCR version does not scan PDFs.

The scan runs in the browser. Always review Merchant, Amount and Date before saving.
